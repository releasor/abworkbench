# Abworkbench

Abworkbench 是一个面向个人的 **效率工作台**（Electron 桌面端）。把日常任务、专注节奏、习惯打卡与资料整理放在同一处，并用全局启动器快速完成搜索与翻译，减少在工具之间来回切换。

React/Vite 仅作为桌面窗口的渲染构建层：不提供独立网页端预览，也不启动 localhost 后端服务。

## 核心能力

- **今日工作台**：仪表盘汇总待办、番茄进度、打卡与天气，一眼看到今天该做什么。
- **任务流**：本地任务管理，支持结构化工作流与模板。
- **番茄钟**：专注计时、休息节奏与每日目标追踪。
- **每日打卡**：习惯养成与连续记录。
- **笔记**：本地笔记与置顶整理。
- **天气**：本地天气速览，辅助安排日程。
- **全局搜索**：启动器接入 Everything，全盘文件秒搜，可直接打开或定位到所在目录。
- **翻译**：在启动器中输入文字即可翻译，支持自定义翻译引擎入口。
- **最近应用**：Alt+Space 展示系统最近应用，并支持模糊搜索已安装应用一键打开。
- **命令面板 / 快捷键**：Ctrl+K 与导航快捷键，键盘即可跳转与执行常用操作。

## Scripts

- `npm run dev`：构建渲染层并启动 Electron 桌面窗口。
- `npm run build`：构建桌面安装包。
- `npm run electron:build`：类型检查、构建渲染层并生成桌面安装包。
- `npm run lint`：运行代码检查。

## Desktop Data

- 任务流数据走桌面本地适配器，不再依赖 `/api`、`localhost:3001` 或 Express 服务。
- 数据保存在 Electron 渲染进程的本地存储中，并在写入前保留最近 8 次 TaskFlow 快照，便于恢复。
- 非 Electron 环境会显示桌面端提示页，不作为网页端入口使用。
- 全局搜索依赖 voidtools Everything（CLI 或内置便携 HTTP 服务）；翻译通过可配置的外部引擎入口完成。
